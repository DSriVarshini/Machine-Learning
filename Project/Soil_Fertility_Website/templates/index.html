01 / OVERVIEW

About the project

Project summary
✳

Soil Fertility Classification Using Decision Tree and Random Forest

This project applies supervised machine learning to classify soil samples from 12 numerical nutrient and chemical parameters. The workflow includes data cleaning, exploratory data analysis, model training, cross-validation, hyperparameter tuning and evaluation.

The trained Random Forest model is connected to this website so a user can enter soil values and view the predicted class, model confidence estimate and class probabilities.

03 / MODEL DEVELOPMENT

Machine learning models

Two classification algorithms were trained and compared.

⑂Baseline model

Decision Tree Classifier

Uses a sequence of feature-based decisions to assign a soil sample to a target class. It is relatively easy to interpret.

  • Splits data using feature values
  • Provides a tree-like decision structure
  • Tuned using GridSearchCV
Tuned test accuracy86.93%
▦Selected for prediction

Random Forest Classifier

Combines predictions from multiple decision trees to produce a more robust classification.

  • Ensemble of decision trees
  • Evaluated with cross-validation
  • Feature importance can be inspected
Reported test accuracy89.20%
